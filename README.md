# Cà Phê Sài Gòn - React + Vite + React Router

## Chạy project
- Windows: double-click file `run.bat`
- Hoặc mở terminal trong VS Code: `npm install` rồi `npm run dev`

Website chạy tại http://localhost:3000

## Các trang
`/`, `/about-us`, `/products`, `/coffee-types`, `/regions`, `/recipes`, `/contact`

## Sửa thông tin
- Thông tin quán, số tài khoản, % đặt cọc: `src/data/shop.js`
- Sản phẩm và giá: `src/data/products.js`
- Loại cà phê, vùng trồng, công thức: `src/data/coffee.js`

## Thay ảnh minh họa bằng ảnh thật
Đặt ảnh `.jpg` vào `public/images/photos/` với đúng tên file bên dưới, website sẽ tự dùng ảnh thật thay cho ảnh minh họa.
- Banner trang chủ: `hero.jpg`
- Trang chủ: `feature-nguyen-chat.jpg`, `feature-rang.jpg`, `feature-kien-thuc.jpg`
- Sản phẩm: `robusta-bmt.jpg`, `arabica-cau-dat.jpg`, `moka-cau-dat.jpg`, `culi.jpg`, `blend-sai-gon.jpg`, `cold-brew.jpg`
- Loại cà phê: `type-robusta.jpg`, `type-arabica.jpg`, `type-moka.jpg`, `type-culi.jpg`, `type-excelsa.jpg`
- Vùng trồng: `region-buon-ma-thuot.jpg`, `region-cau-dat.jpg`, `region-khe-sanh.jpg`, `region-son-la.jpg`
- Công thức: `recipe-phin.jpg`, `recipe-bac-xiu.jpg`, `recipe-ca-phe-muoi.jpg`, `recipe-cold-brew.jpg`, `recipe-ca-phe-trung.jpg`
- Thưởng thức: `style-phin-cham.jpg`, `style-sua-da.jpg`, `style-den-nong.jpg`, `style-banh.jpg`
Tỷ lệ ảnh nên là 3:2 (ví dụ 1200x800).
